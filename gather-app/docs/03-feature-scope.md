# Feature scope

## Phase 1 — private housewarming MVP

- Email magic-link authentication.
- Optional phone verification later, not required to launch the pilot.
- Basic profile with display name, avatar, pronouns optional, and verification state.
- Create, edit, cancel, and close a private event.
- Invitation links with expiry and revocation.
- Host approval queue.
- Controlled plus-one proposals.
- RSVP and dietary/accessibility notes.
- Sensitive detail reveal after approval.
- Calendar file export and add-to-calendar links.
- Event updates, not a full free-form chat.
- Private photo capsule with maximum three uploads per approved attendee.
- Polaroid rendering and lightweight reactions.
- Blocking, reporting, invite revocation, and account deletion request.

## Phase 2 — trust network

- Friend connections and circles.
- Reusable guest groups.
- Mutual-context indicators such as “invited by Alex”.
- Private host feedback dashboard.
- Event templates.
- Push notifications.

## Phase 3 — verified open events experiment

This phase requires separate threat modelling, age policy, moderation operations, identity/vendor review, and legal review.

- Adults only at launch.
- Strong identity and liveness verification through a specialist provider.
- No exact residential address before mutual approval.
- Venue risk categories and stricter rules for private homes.
- Capacity, reporting, emergency, and moderation tools.
- Discovery that limits precise location and avoids exposing vulnerable users.

## Explicitly rejected for now

- Five-star public host or event ratings.
- Public attendee counts as social proof by default.
- “People you may know” based on uploaded address books without explicit consent.
- Unlimited photo uploads.
- Public comments on private memories.
- Under-18 open events.
