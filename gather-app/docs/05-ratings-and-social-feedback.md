# Social feedback without popularity scoring

## Decision

Do not launch public five-star host or event ratings. They invite popularity contests, retaliation, social bias, manipulation, and pressure to optimise for spectacle rather than belonging.

## Replacement: private host appreciation

After an event, attendees may send:

- a private thank-you reaction;
- structured private signals such as “welcoming”, “well organised”, “great food”, “good introductions”, and “would attend again”;
- an optional private note to the host.

The host sees aggregate feedback only after a minimum response threshold. Guests do not see one another’s feedback.

## Profile expression

Instead of scores, profiles may show self-selected hosting badges earned through transparent milestones, for example:

- First gathering hosted;
- Brought three circles together;
- Hosted five gatherings;
- Created a complete memory capsule.

Badges must describe activity, not quality or social worth. Users can hide badges.

## Reactions to photos

Use a small set of warm reactions and one optional comment thread per photo. Reactions are visible only inside the event and do not create global counts on profiles.
