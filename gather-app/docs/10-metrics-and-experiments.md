# Metrics and experiments

## Activation funnel

- account verified;
- event draft started;
- event published;
- first invitation opened;
- first attendee approved;
- four approved attendees;
- event completed;
- first photo uploaded;
- memory capsule viewed.

## Quality metrics

- invitation-to-RSVP conversion;
- median host approval time;
- percentage of plus-one requests approved;
- address reveal failures;
- upload success rate;
- report and block rate per event;
- event cancellation rate;
- attendee return rate within 60 days;
- private “would attend again” aggregate.

## Guardrail metrics

- unauthorised detail access attempts;
- leaked or long-lived signed URL incidents;
- spam invitations per active account;
- reports involving underage concerns;
- non-consensual image reports;
- account deletion completion time.

## First experiments

1. Invite page with app-free RSVP versus mandatory account creation.
2. Broad-area wording that builds confidence without revealing a home.
3. Three-photo cap versus five-photo cap.
4. Plus-one context prompt versus no context prompt.
5. Post-event capsule notification timing.
